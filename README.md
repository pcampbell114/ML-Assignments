# Machine Learning Assignments

This repo contains my ML coursework from CSE 546 - Machine Learning at UW, organized by branch:

- `PyTorch-Manual` — Building manual layers of neural network as classes similar in construction to built-in functions for PyTorch and testing it on custom data set
- `Kernel-Bootstrap` - Implement two kernel functions: Polynomial and Radial Basis Function (RBF). For each one, we:
    1. Search with cross-validation to find optimal parameters
    2. Plot trained function on custom data
- `Neural-Network-MNIST` - Build and implement two custom neural networks and train+test them on custom data set for comparison. Layers of networks are ReLUs and Linear Regressions
